# Riesgo Cardiovascular (RCV)

**ICESI · Máster en Inteligencia Artificial Aplicada**

Modelo predictivo del riesgo cardiovascular en pacientes de la ESE Oriente (comunas 13, 14, 15 y 21 de Cali) entre 2019 y 2023, desarrollado bajo la metodología CRISP-DM.

## Contenido

| Archivo / Carpeta | Descripción |
|---|---|
| `scripts/` | Notebooks del pipeline: conversión a parquet, unificación, formatos, análisis exploratorio y modelos |
| `main.py` | Script principal |
| `data/` | Datos (`raw`, `processed`, `external`) |
| `context.txt` | Contexto y objetivos del reto |
| `Diapositivas ICESI.pdf` | Presentación del proyecto |
| `requirements.txt` | Dependencias del proyecto |

## Tecnologías

- Python 3
- `pandas`, `numpy`, `scikit-learn`, `matplotlib`
